# SalesLeads Demo

Landing page demo untuk jasa website katalog kendaraan dan lead generation WhatsApp.

## Setup lokal

```bash
npm install
npm run dev
```

Buka http://localhost:3000.

## Sebelum deploy

Edit `src/app/page.tsx` dan ganti `WHATSAPP_NUMBER` dengan nomor WhatsApp bisnis yang benar (format internasional tanpa `+`, spasi, atau angka 0 awal).

Harga kendaraan pada katalog adalah contoh ilustratif. Perbarui sesuai penawaran yang valid atau biarkan catatan demo terlihat.

## Build

```bash
npm run build
```
